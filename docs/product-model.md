# Next Level Ops — Product Model

## What this product is

Role-based operations dashboard for a fitness studio.

## Users

- Admin
- Client

## Admin goals

- manage members
- manage trainers
- manage membership plans
- manage sessions
- manage bookings
- monitor statuses and operations

## Client goals

- view profile
- view active membership
- view upcoming bookings
- cancel booking if allowed

## Product goal

Build a production-shaped business app that demonstrates strong hiring signals for frontend roles.

## Anti-scope

- trainer portal
- payments
- deep analytics
- React Native
- notifications
- offline/PWA depth
- calendar sync
- extra roles
